# Portfolio Gustia Nayla

Website portfolio pribadi yang dibuat menggunakan HTML, CSS, dan JavaScript.

## Deskripsi

Portfolio ini digunakan untuk memperkenalkan diri, pendidikan, skill, hobi, dan cita-cita.

Website menggunakan kombinasi warna biru navy, biru muda, dan putih pastel.

## Struktur Folder

portfolio/

│

├── index.html

├── about.html

├── contact.html

├── style.css

├── script.js

├── README.md

│

└── images/

    └── foto-saya.jpeg

## Cara Menjalankan

1. Buat folder bernama portfolio.
2. Masukkan index.html.
3. Masukkan about.html.
4. Masukkan contact.html.
5. Masukkan style.css.
6. Masukkan script.js.
7. Masukkan README.md.
8. Buat folder images.
9. Masukkan foto ke folder images.
10. Beri nama foto foto-saya.jpeg.
11. Buka index.html menggunakan browser.
